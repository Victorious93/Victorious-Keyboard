AI and LLM vocabulary
Terms, parameter names, models, products and libraries used when working with large language models. Proper-noun spellings; availability of each name was not checked online.

Contents: 177 words, installed for all languages into the keyboard's internal user dictionary.
Names only: no options, no commands with arguments, no descriptions, no text from any manual.
Provenance: curated by the Victorious Keyboard contributors from memory. NOT checked against the current official
documentation or package lists (the review environment had no network access), so a name may be missing, renamed or
removed in a newer release. Edit freely: this is a plain word list (see pack.json and words.txt).
